## johncompany.app 

A web companion app simulating the **Events in India** for *John Company: Second Edition*.

## Quick Start

```bash
# Clone the repository
git clone https://github.com/blakekwehrle/johncompany-app.git

# Install dependencies
npm install

# Run locally
npx vite --port 4000
```
